# Handoff：weiliang.dev 全站改版

## 一、这是什么

weiliang.dev（个人网站）的视觉改版定稿。目标是**替换掉现有那套「黑白设计系统」**，全站换成「雾蓝底 + 蓝/橙双主色 + 玻璃卡面 + 手写标题」的新面貌，**信息架构、内容管线、路由、部署方式一律不动**。

- 现有站点：Next.js 16（App Router）+ Tailwind CSS 4 + next-intl，内容是仓库里的 markdown（`content/`），`next build` 静态导出到 `out/`。
- 改的是视觉层与内容：`src/app/globals.css` 的 token + `src/components/**` 的表现 + `content/` 的文案。

**三件硬要求（定稿，不要偏离）**

1. 文案全量换成 `content.md` 里的，**逐字照抄**；旧 `content/` 里的文案全部作废。
2. 图片全量用本包 `assets/` 里的（尤其首页那张海报 `assets/hero/poster.png`），对应位置见 §九。
3. 预设以**当前定稿**为准：无底纹、首页头像是拍立得、导航是左右分立（底部渐变下法线）、没有滚动进度条。
- 同时**精简功能范围**：只保留设计稿里出现的页面，加上音乐；其余旧功能全部下线。详见 §二半。
- 不改：`messages/`、`src/i18n/`、`site.config.ts`、部署配置；保留页面对应的 `content/` 与 `scripts/` 不动。

## 二、关于这个包里的设计文件

`reference/` 里的 HTML 是**设计参考稿，不是可以拷进仓库的生产代码**。它用一套独立的 CSS 变量体系在浏览器里把最终效果搭了出来，页面切换是本地 state，不是真路由；内容是写死的示例文本。

你要做的是：**在现有 Next.js + Tailwind 4 代码库里，用它已有的组件结构和写法，把这份设计重新实现出来。**按本文件的 token 表和组件说明改，不要照搬参考稿的 DOM。

打开方式：直接用浏览器打开 `reference/weiliang-redesign-reference.html`（单文件、离线可用，字体和图片都已内嵌）。导航栏可以逐页点，首页头像有鼠标视差，往下滚能看到错位滑入动效和顶部进度条。

## 五、三层全站效果（这是改版的"体感"来源，务必实现）

### 1. 玻璃卡面

所有卡片、导航栏、输入框：

```css
background: color-mix(in srgb, var(--color-surface) 42%, transparent);
backdrop-filter: blur(20px) saturate(1.4);
border: 1px solid color-mix(in srgb, var(--color-ink) 14%, transparent);
box-shadow: 0 10px 36px color-mix(in srgb, var(--color-ink) 16%, transparent);
```

次要按钮是 45% + `blur(14px)` + 16% 描边；标签是 `accent 22%` + `blur(10px)`；主按钮实色填充 + `0 8px 26px accent@45%` 外发光。

因为卡面是半透明的，**底纹和光斑必须在它后面透出来**——这是整套视觉成立的前提。任何一处把卡面改成实色白，那块就会显得像贴上去的。

### 2. 背景：只有两颗漂移光斑

底纹网格已经**关掉**（定稿：无底纹）——不要画网格、不要圆点阵、不要纸纹。背景就是纯 `--color-bg` 加两颗光斑：

- 680px 圆、`blur(46px)`、`opacity .95`。
- A 在右上（`top:-180 right:-140`，蓝 `accent-200`，26s 循环）；B 在左中（`top:640 left:-220`，橙 `accent-2-200`，32s 循环）。
- 缓动 `ease-in-out`，位移见 `tokens.css` 的 `wlDrift/wlDrift2`。

`tokens.css` 里的 `.bg-texture` 一条是**备用**，本次不要挂到页面上。玻璃卡面仍然是半透明的，透出来的是底色和光斑。

### 3. 翻阅动效「错位滑入」（强度 k = 1.6）

滚动进入视口时，块级内容左右交替滑入：

- 初始：`translate3d(-96px * 1.6, 18px * 1.6, 0) scale(.965)`，`opacity 0`；奇数序号的块从 **+153.6px**（右侧）进。
- 终态：`opacity 1; transform: none`。
- 过渡：`opacity .6s ease, transform .86s cubic-bezier(.16,.86,.22,1)`。
- 错峰延迟：`(index % 4) * 110ms`。
- 触发：`IntersectionObserver`，`rootMargin: "0px 0px -16% 0px"`，`threshold: 0.04`，触发后 `unobserve`。另挂一个 1600ms 的兜底定时器，把还没触发的全部置为可见（防止图片未加载导致空白）。
- 选取目标：页面主容器的直接子节点；若某个子节点内部有 ≥2 个 `.card / article / section`，则改取这些内部元素作为动画单元（卡片网格是一张张分别进，不是整块进）。
- 换页时整个 `main` 播一次 `wlPgSlide .55s cubic-bezier(.2,.8,.3,1)`（从 `translateX(44px)` + 透明进入）。
- **顶部滚动进度条：不要**（定稿已关）。`tokens.css` 里的 `.scroll-progress` 是备用，不要挂上。
- `prefers-reduced-motion: reduce` 下全部关闭（已写在 `tokens.css`）。

## 七、交互与状态

- 焦点环：`:focus-visible { outline: 2px solid var(--color-accent); outline-offset: 2px }`，全站统一，不要留浏览器默认。
- hover 位移统一两档：卡片 `translateY(-6px)`，行式元素 `translateX(6–8px)`；过渡 `.25–.35s ease`。
- 禁用态 `opacity .45`。
- 保留的交互只有三项：中英双语切换、迷你播放器（音乐）、视频懒加载。其余旧交互（⌘K、番茄钟、便签、评论、新闻面板）随 §二半 一起下线。
- 滚动进度条不要做。
- 播放器换皮：用玻璃卡面 + 999px 胶囊控件，进度条用主色；保持现有的 `localStorage` 播放位置恢复逻辑。
- 响应式：所有网格用 `repeat(auto-fit, minmax(...))`，参考稿没画移动端，断点按现有站的做法处理；顶栏在窄屏沿用现有折叠方案。手机上触摸目标不小于 44px。
- 暗色/浅色：本次不引入暗色模式开关；「暗侧」仅指侧栏、开场页、放松区这些本来就是深色的区域。

## 八、状态管理

改版不新增任何全局状态。参考稿里的页面切换是演示用的本地 state，实现时走真实路由。需要客户端 state 的只有：
- `Reveal` 的 IntersectionObserver（已有组件，改动效实现即可）；
- 首页头像的鼠标视差（`onMouseMove` / `onMouseLeave`，直接写 DOM style，不要进 React state）；
- 视频播放器的懒加载开关（现有逻辑）。

## 十、落地顺序建议

0. **先做范围精简**（§二半）：删路由、删组件、改 `nav.ts`、清文案与脚本，`npm run build` 跑通。先把面积缩小再换皮，能省一大半的改动量。
1. `globals.css`：换 `@theme` token 块（`tokens.css` 第一段），加玻璃/底纹/动效基础层（第二、三段）。然后**全局搜一遍硬编码的灰色值**——原黑白系统留下的 `#111`/`#333`/`#666`/`#999`/`#e5e5e5` 之类，全部换成 token。
2. `layout.tsx`：挂上三个新字体。
3. `SiteShell` + `TopNav` + 页脚：外壳先立起来，这一步做完全站就已经"换脸"了。
4. `Reveal` / `PageFade`：换动效。
5. 逐页改组件：首页 → 关于 → 项目 → 博客 → 视频 → 摄影 → 工具 → 联系。
6. 改音乐页（`/records`：转盘、唱片墙、榜单）与迷你播放器的皮。它是唯一保留的旧功能，设计稿里没画——按新 token 重色、卡面玻璃化、控件胶囊化即可，不要重构功能。原 `shell-*` / `desk-*` token 组在删掉暗侧页面后如果已经没人用，一并从 `globals.css` 里去掉。
7. `npm run build` 静态导出跑通，确认 `out/` 正常，再切上线。
