# 如何往网站上加照片

> 写给站主自己看的。不需要懂前端。
> 摄影页在 https://weiliang.dev/zh/photos/ ，顶栏「摄影」。

2026-09-17 改版之后**没有压图脚本了**（`npm run photos`、`photos-src/` 都已下线）：
照片自己先导出成合适的大小，手动放进去，再改一个 json 文件。

## 现在站上有哪几辑

| 文件 | 标题 | 年份 | 照片 |
|---|---|---|---|
| `content/photos/shanghai.json` | 上海 | 2025 | shanghai-01 / shanghai-02 |
| `content/photos/beijing.json` | 北京 | 2023 | beijing-01 / beijing-03 |
| `content/photos/qingdao.json` | 青岛 | 2024 | qingdao-01 / qingdao-04 |

图片都在 `public/images/photos/` 下。

## 给某一辑加一张

1. **导出图片**：webp 或 jpg，长边 2000px 左右、一张几百 KB 以内（别直接放几 MB 的原图，
   仓库会越滚越大、页面也慢）。iPhone 的 HEIC 先导出成 JPEG。
   顺手把 EXIF（尤其是位置信息）去掉 —— 大多数导出工具有这个选项。
2. **放进** `public/images/photos/`，文件名用英文小写 + 短横线，比如 `shanghai-03.webp`。
3. **查尺寸**：Mac 上选中图片按 ⌘I（或者终端 `sips -g pixelWidth -g pixelHeight 文件名`），
   记下宽和高。
4. **改那一辑的 json**，在 `photos` 里加一条：

```json
{ "file": "shanghai-03.webp", "width": 2000, "height": 1500, "caption": "外滩的早上" }
```

| 字段 | 填什么 |
|---|---|
| `file` | 第 2 步的文件名 |
| `width` / `height` | 第 3 步查到的像素尺寸（照实填，页面排版要用） |
| `caption` | 图注，照片下面那行小字。不想写就删掉这个字段 |
| `captionEn` | 英文图注（可选；不写英文页就显示中文） |

照片的先后就是 `photos` 数组里的先后。

## 新开一辑

在 `content/photos/` 新建一个 json，**文件名就是网址**（`busan.json` → `/zh/photos/busan/`）：

```json
{
  "title": "釜山",
  "year": "2025",
  "order": 4,
  "photos": [
    { "file": "busan-01.webp", "width": 2000, "height": 1333, "caption": "海边" }
  ]
}
```

- `year`：显示成「2025 · 1 张」里的那个年份
- `order`：摄影页上的先后，小的在前（现在是 上海 1 / 北京 2 / 青岛 3）
- `titleEn`：英文标题（可选）

## 删一张 / 删一辑

- 删一张：从 json 的 `photos` 里删掉那一条，再删掉 `public/images/photos/` 里对应的图。
- 删一辑：删掉那个 json，和它用到的图。

## 看一眼，然后提交

```
npm run dev
```
浏览器打开 http://localhost:3000/zh/photos/ 看看。没问题就：

```
git add -A
git commit -m "摄影：加了釜山那一辑"
git push
```

## 几个可能会问的

**照片为什么看起来有点灰？** 页面上的照片统一做了「washed」处理（去饱和、抬亮），
让它沉进雾蓝底色里；鼠标移上去就恢复原色，点进单辑页再点开看大图，是完全原色的整张。
**图片文件本身没被改过**。

**网格里为什么被裁了？** 网格统一裁成 4:3（整齐）。点进这一辑、再点开照片，看到的是完整未裁的整帧。
